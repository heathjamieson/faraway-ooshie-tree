# The Faraway Ooshie Tree

An animated homage to Enid Blyton's Faraway Tree: Moana leads eleven Ooshie-style characters through the Enchanted Wood, up the tree and through the clouds to a new land at the top.

Single self-contained `index.html` (canvas animation, no build step). Fan-made; not affiliated with Woolworths, Disney, Marvel or the Blyton estate.
